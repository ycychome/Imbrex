# M0 输入边界与认证验证

日期：2026-10-18。此记录覆盖 M0-03 的事件/JSON/HTTP DTO 校验及 M0-02 的配置与认证部分，不代表宿主启动或完整 M0 已完成。

实现集中于 src/core、src/host/config.ts、src/adapters/http/dto.ts。核心没有 HTTP 或 Cordis 依赖；外部参数为 unknown，校验后收敛并保存 JSON 快照。

验证命令：锁定 Node 24.22.0 / npm 11.19.1 下执行 npm run check。新增 6 项测试针对以下实际风险：

- T03：超安全整数的位置经 HTTP 字符串无损往返，拒绝非规范序号、重复参数和非法页大小。
- T02/T05：拒绝超限、重复父引用、非法信封和无法无损 JSON 序列化的值；防止调用后修改原对象影响保存快照。
- T05：schema 词汇白名单拒绝外部引用与未支持特性；参数校验不强转、不删除字段。
- T05：配置重复身份、重复/缺失凭据或未知主体必须失败，错误不包含凭据；认证后的授权按字面来源和精确能力 ID 执行。

已有 4 项依赖探针继续运行。实例锁、SQLite worker、能力派发及完整 HTTP 请求链路将由后续 PR 验证。

独立审核复现并修复了根布尔 schema、继承属性满足 required、__proto__ 约束被跳过、URI 非法字符及闰秒位置五项问题；新增 2 组对应回归测试，覆盖有效布尔 schema、自有属性要求、非法定义拒绝、原始 URI 字符检查及带偏移的 UTC 月末闰秒位置。
